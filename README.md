# Codeforces DSA & CP Master Sheet 🚀

A high-performance, dark-themed Competitive Programming & Data Structures sheet inspired by Striver's SDE/DSA Sheet, mapped directly to **Codeforces** problems.

## 🌟 Key Features

- **16 Comprehensive Topics**: 345 curated problems spanning Arrays, Binary Search, Strings, Two Pointers & Sliding Window, Bit Manipulation, Stack & Queues, Greedy Algorithms, Trees, Graphs, Dynamic Programming, Disjoint Set Union (DSU), Segment Trees, and more.
- **Easy → Medium → Hard Progression**: Problems sorted by difficulty tier and popularity (Codeforces solved count) with actual ratings from 800 to 2000+.
- **Direct Codeforces Integration**:
  - Every problem links directly to `https://codeforces.com/problemset/problem/{contestId}/{index}`.
  - **Sync CF Handle**: Enter your Codeforces username to automatically fetch your submissions and auto-check every problem you've solved!
- **Interactive Tracking**:
  - Checkboxes to mark solved problems with smooth animation.
  - Live progress bar for each topic and global completion counter in the header.
  - Full persistence using browser `localStorage`.
- **Search & Advanced Filters**:
  - Live search by problem title, CF ID (e.g., `#71A`), or tags.
  - Filter by Difficulty (All, Easy, Medium, Hard), Status (Solved / Unsolved), and Sort by Rating or Solved Count.
- **CP Utilities**:
  - **Random Problem Picker**: Challenge yourself with a random unsolved problem.
  - **Analytics & Backup**: Export and Import your progress as JSON anytime.
